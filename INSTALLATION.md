# Instalacja zależności

Aby uruchomić projekt z nowym headerem, musisz zainstalować brakującą zależność:

```bash
npm install next-themes
```

## Brakująca zależność:

- ❌ next-themes

## Po instalacji:

1. Uruchom projekt: `npm run dev`
2. Header będzie dostępny na górze strony
3. Możesz testować:
   - Zmianę motywu (jasny/ciemny)
   - Zmianę języka (PL, EN, DE, FR, ES)
   - Responsywność na urządzeniach mobilnych
   - Nawigację między sekcjami

## Funkcje headera:

### 🎨 Zmiana motywu

- Toggle między jasnym a ciemnym motywem
- Automatyczne wykrywanie preferencji systemu
- Płynne przejścia

### 🌍 Zmiana języka

- 5 dostępnych języków z flagami
- Dropdown menu na desktop
- Select na mobile
- Przygotowane pod internacjonalizację

### 📱 Responsywność

- Menu mobilne z hamburgerem
- Adaptacyjny layout
- Touch-friendly na urządzeniach mobilnych

### 🎯 Nawigacja

- Smooth scroll do sekcji
- Aktywne stany linków
- CTA button "Get Started"
